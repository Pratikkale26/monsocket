# monsocket docs

monsocket is an open-source realtime multiplayer SDK for Monad.

It gives developers a small room API for collaborative and multiplayer onchain apps:

- rooms
- player presence
- realtime events
- shared room state
- free read-only spectating

The flagship demo is **The Vault**, a two-player onchain escape room built directly on top of the SDK.
